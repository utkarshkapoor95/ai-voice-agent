Based on Production Infrastructure

The outbound workflow architecture is adapted from a production system that made 5,000+ outbound calls with an ~8% positive response rate (~400 qualified leads) during a real client engagement. The production system ran daily scheduled campaigns with Airtable as the data store.

Security

Telegram Approval Gate

Both demos are gated to prevent unauthorized API credit usage.

Owner-Only Activation

Every demo trigger sends a Telegram message. Calls proceed only after explicit approval.

Credit Protection

No anonymous visitor can burn Vapi or Bolna credits. The gate blocks all unauthorized calls.

Sanitized Workflows

All API keys, agent IDs, and client details are stripped from public workflow files.
