Architecture

How It Works

● Inbound Pipeline

1
User clicks "Talk" in the browser
2
Vapi Web SDK opens a WebRTC voice channel
3
Soniox STT transcribes speech in real time
4
GPT-4.1 processes the query against business data
5
ElevenLabs synthesizes the AI response as natural speech
6
Vapi Dashboard logs the call with full transcript

● Outbound Pipeline

1
User submits form with name, company, scenario
2
n8n webhook receives data, applies rate limiting
3
Telegram bot sends approval request to owner
4
Bolna API places the call to the demo number
5
Groq LLM classifies the call transcript post-call
6
Google Sheets logs lead data, transcript, and classification
