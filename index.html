Two distinct pipelines, each optimized for its channel. Data flows through n8n with Groq intent classification and automated follow-ups.

One System, Two Channels, Fully Customizable

Both agents share the same n8n backbone. A single business can deploy inbound reception for customer calls and outbound qualification for lead generation simultaneously, with shared Google Sheets tracking, unified Telegram alerts, and coordinated Brevo email sequences. The architecture is modular: swap the LLM, change the voice, add new branches, or connect a CRM, all without touching the agents themselves.

Based on Production Infrastructure

The outbound workflow architecture is adapted from a production system that made 5,000+ outbound calls with an ~8% positive response rate (~400 qualified leads) during a real client engagement. The production system ran daily scheduled campaigns with Airtable as the data store.

Security

Demo Abuse Protection

The live demo is protected server-side so visitors cannot drain API credits.

Server-Side Rate Limiting

The n8n gate allows one demo call per hour and caps daily usage. Excess requests are rejected before any API is touched.

Credit Protection

Outbound calls only go to the owner's verified number, and every trigger sends an instant Telegram alert to the owner.

Sanitized Workflows

All API keys, agent IDs, and client details are stripped from public workflow files.
